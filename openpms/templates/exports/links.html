Data links for BI tools

A data link is a private web address that serves live, read-only CSV files. Power BI, Excel, Google Sheets, Looker Studio and most other tools can read it and refresh on a schedule, with no sign-in.

Anyone who has the link can read the data, so treat it like a password. Turn a link off as soon as it's no longer needed. Data links never include wellbeing, review comments or the audit log.
