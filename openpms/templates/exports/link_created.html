How to connect

  • Power BI: Get data, Web, paste the address of a CSV file. Set a scheduled refresh in the Power BI service.
  • Excel: Data, From Web, paste the address of a CSV file. Use Refresh All to update.
  • Google Sheets: in a cell, type =IMPORTDATA("address of a CSV file").
  • Looker Studio and other tools: use their CSV or web connector with the address of a CSV file.

Each request reads the live data, so values update as soon as they're approved.
